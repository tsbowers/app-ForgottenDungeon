# Forgotten Dungeon

## Overview

Forgotten Dungeon is an Android mobile game built around luck, adventure, and dungeon exploration. The goal of the project is to create an interactive gaming experience where players can explore a fantasy dungeon, encounter monsters, roll dice to determine outcomes, and use a shop to improve their chances of survival.

Players interact with the game through its on-screen controls. Dice rolls introduce an element of randomness, making each encounter an opportunity to experience a different outcome. The shop provides a way to expand the game's items and give players more options as they progress through their adventure.

I created Forgotten Dungeon to develop my skills as a software engineer by learning how to design, build, and improve an interactive mobile application. This project has helped me gain experience with Android development, user interface design, application logic, and connecting user interactions to game outcomes. It also gives me an opportunity to explore how game mechanics can be combined to create an engaging mobile experience.

My future goals are to expand the game with additional shop items, monster artwork, more monster encounters, and an animated dice-rolling effect. These improvements will make the game more visually appealing and add variety to the player's experience.

## Development Environment

The application was developed using the following tools and technologies:

- **Android Studio:** The integrated development environment used to build, run, and debug the Android application.
- **Kotlin:** The programming language used for Android development.
- **Gradle:** The build system used to configure the project and manage its build process.
- **Jetpack Compose:** Android's modern UI toolkit, indicated by the project's Kotlin Compose Gradle configuration. It provides tools for building user interfaces with Kotlin.
- **Android Emulator:** Used to run and test the application in a virtual Android device.
- **Git and GitHub:** Used for version control, storing the source code, and tracking project changes.

Kotlin supports object-oriented and functional programming features, making it useful for organizing game logic and managing interactions. Android Studio provides tools for testing and debugging the application, while Gradle helps manage the project's configuration and dependencies.
